## Order of work

1. **Finish local integration and checks:** canonical route boundaries, isolated visible Work preview, native canonical/fallback fixtures and original dashboard inspection are complete. The changed-source/native regression and rendered checks passed; review the candidate without replacing the running bundle. Preserve the accepted physical hotkey, Island, audible reply and mute behavior. The original server's latest approved preflight is **14 pass, 0 fail, 2 warn**.
2. **Complete task safety:** extend the completed durable note approvals and exact-revision undo to individually supported action classes using the existing journal/gateway. The two-task source and Work preview are implemented; integrated and live acceptance remain separate gates. Keep existing routes intact during migration.
3. **Accept the native experience:** test cancel, exact recognition, rendered transitions, accessibility settings, screen-share privacy, click-through, Spaces/displays and end-to-end latency/CPU. Stable signing has no available identity on the discovered Mac. Merge/restart/startup changes require explicit approval.
4. **Make background delivery trustworthy:** use verified completion/approval events, queue around active speech, and add permissioned presence/quiet-hours signals. Measure missed and duplicate updates. Extend the new on-demand readiness into reviewed daily operations and add unified activity, then complete the pending manual/model-backed portion of the 30-task evaluation before claiming the full foundations complete.
5. **Offer hands-free listening only after a privacy review:** start with an optional local wake word; measure false activations and battery use. Double-clap and follow-up listening follow the same gate.
6. **Grow tools and devices by permissioned slices:** evaluate each integration for cost, maintenance, authentication and reversibility. Retain the existing rejection of paid fallback and the retired Focus feature.

The existing [execution upgrade checklist](upgrade-checklist.md) still governs Deep Agents, remote workspaces and evaluated learning. Its open gates are not passed by this voice branch.
