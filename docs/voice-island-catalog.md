# Jarvis feature catalog and roadmap — 2026-10-28

Statuses describe this worktree and observed running system. **Verified working** means exercised locally; **partial** means a real implementation exists with an open acceptance or integration gate; **missing** means no implementation was found; **blocked** means external access, a supplied detail or explicit activation is required. Effort is a rough order-of-magnitude estimate for the next meaningful slice, not a commitment.

The original installation and previously accepted voice helper are preserved. New brain, operations, preference and hands-free features below are prepared in the isolated candidate. Obsidian is staged, not installed. See the [current build/acceptance plan](BUILD-PLAN.md); earlier regression counts do not describe this expansion.

## Order of work

1. **Complete reviewed setup and live acceptance:** automated integration checks and isolated visible UI checks pass; review Obsidian installation and separate-brain activation next. Preserve the original server and accepted hotkey/Island/reply/mute helper until replacement is approved. Historical original-server preflight does not validate the candidate.
2. **Accept supported action safety:** exercise exact note/preference save, reject, conflict, expiry, restart and undo in the activated candidate. Broader action classes require their own explicit scope and compensators. The two-task source and Work preview still need representative live trials.
3. **Accept the native experience:** test cancel, exact recognition, rendered transitions, accessibility settings, screen-share privacy, click-through, Spaces/displays and end-to-end latency/CPU. Stable signing has no available identity on the discovered Mac. Merge/restart/startup changes require explicit approval.
4. **Accept delivery and local operations:** verify quiet-hours boundaries, native/web speech settings, bounded deferral, real local signals, daily checks, activity and selected exports. Measure missed and duplicate updates; finish the manual/model-backed portion of the 30-task evaluation. Calls/sharing/DND are not inferred.
5. **Treat hands-free as preview:** after explicit microphone consent, test wake accuracy/false activations, final words, follow-up, HF/PTT handoffs, early release, Escape/mute and session/sleep shutdown. Disable it before locking until immediate lock behavior is verified. Measure battery/CPU; double-clap remains deferred.
6. **Grow tools and devices by permissioned slices:** evaluate each integration for cost, maintenance, authentication and reversibility. Retain the existing rejection of paid fallback and the retired Focus feature.

The existing [execution upgrade checklist](upgrade-checklist.md) still governs Deep Agents, remote workspaces and evaluated learning. Its open gates are not passed by this voice branch.
